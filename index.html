What it is

Swiss hockey, last minute

Alles Hockey is the phone app for finding or posting short-lived needs — players, goalies, ice time — and moving used gear fast. Invite-only while we sharpen the closed beta.

  • Last Minute HS Cards with time, place, level. Contact only when someone taps through.
  • 2ndChance Used sticks, pads, skates — listings expire so the board stays fresh.
  • Map See what’s nearby when you’re already laced up.
